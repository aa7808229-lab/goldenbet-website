# GoldenBet

GoldenBet is a modern sports and casino website built with React and Vite.

## Features

- Sports and football matches
- Betting slip
- Live matches
- Casino
- Live Casino
- Golden Games
- User registration and login
- User profile
- Balance, deposit and withdrawal pages
- Multi-language support
- Country-based content
- Supabase integration
- Admin dashboard
- Responsive mobile design

## Technology

- React
- Vite
- React Router
- Supabase
- Express
- Node.js
